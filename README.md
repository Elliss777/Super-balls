# Супер Шарики

Браузерная головоломка «три в ряд» в стиле старой Windows-игры «Супер Шарики».

## Запуск

Откройте файл `super-shariki.html` в любом современном браузере. Установка не нужна.

## Правила

- Выберите шарик, затем соседний, чтобы поменять их местами. Ход засчитывается, только если получилась линия из трёх и больше одинаковых шариков.
- Бомба очищает квадрат 3×3 вокруг выбранного шара. Стартовых бомб три, за каждые 1000 очков добавляется ещё одна.
- Уровни: «Легкая» (140 с, 5 цветов), «Средняя» (120 с, 6 цветов), «Трудная» (100 с, 7 цветов).

## Файлы

- `super-shariki.html` — вся игра в одном файле (HTML, CSS и JavaScript).
